An artifact is a standalone, working output in its own window beside the conversation. Instead of a wall of code buried in the chat, you get the thing itself — rendered, runnable, downloadable.

You're looking at one right now. This page is a single HTML file — type 03 on the specimen sheet below. Everything the lesson describes is what made it.

Station 01

Why one appears

You don't switch artifacts on. Claude makes one when the content passes four tests — which is also the recipe for asking for one deliberately.

Test 01

Substantial and self-contained

Typically more than fifteen lines. Big enough that burying it in the chat would be doing it a disservice.

Test 02

You'll want to change it

Something you'll edit, iterate on or reuse — not a one-time answer you read and move past.

Test 03

It stands alone

Complex content that makes sense without the conversation wrapped around it.

Test 04

You'll come back to it

Content you'll reference or use later, somewhere other than this chat.

Say this"Create a flowchart showing our customer onboarding process."
Say this"Build an interactive dashboard that lets me input monthly expenses and see a breakdown."
Say this"Design a landing page for a productivity app with a hero section and feature list."
Say this"Write a project brief template I can reuse for new initiatives."

When it doesn't happen

Ask for something substantial and get a wall of text in the chat instead? You don't have to rephrase the whole request. Just say "Create this as an artifact" or "Show me this in an artifact." The override is one sentence.

Station 02

The specimen sheet

Six forms an artifact can take. The previews below show the shape of each one, so you can recognise which you're asking for.

Type 01

Document

Markdown or plain text, for anything text-heavy you'll export or keep editing.

Project brief — Q3 launch
• Scope   • Owner   • Deadline

Good for meeting notes, reports, project plans, blog posts.

Type 02

Code snippet

Working code in any language. View it, copy it, or download it into your own project.

# monthly totals
def total(items):
    return sum(
        i.price for i in items
    )

Good for Python, JavaScript, C++ and everything else.

Type 03

HTML page

A complete web page — HTML, CSS and JavaScript in a single file.

Focus — do less, finish more
Start free

Good for landing pages, forms, demos, quick prototypes.

Type 04

SVG image

Scalable vector graphics that render right in the window, so you see exactly what you're getting.

Good for logos, icons, illustrations, diagrams by hand.

Good for flowcharts, sequence diagrams, Gantt charts, org charts. Note: flowcharts may now come back as an HTML visual rather than Mermaid code — same idea, different rendering.

Office files come back a different way

Word documents, Excel spreadsheets, PowerPoint decks and PDFs are made through a separate file-creation capability, not the artifact panel. Same conversation, different mechanism — Claude hands these back as files you download, so don't wait for them to appear in the window on the right.

Station 03

Working in the window

The artifact opens in its own panel beside the conversation. Four things you can do there, and three habits that decide how good the result gets.

01
Toggle preview and codeSee how it looks, or see what it's made of. Switch freely between the two.
02
CopyGrab the contents to use somewhere else.
03
DownloadSave it to your computer as a file.
04
View the code underneathExactly what Claude generated — useful for checking, learning, or taking it elsewhere.
Habit 01

Be specific about what you want

The vague version isn't wrong, it's just under-specified — so Claude fills the gaps with guesses instead of your requirements.

Good"Build a budget tracker"
Better"Build a monthly budget tracker where I can input expenses by category, see a pie chart breakdown, and get a warning when I'm over budget"
Habit 02

Say who it's for

The end user drives the design choices. "This flowchart is for new employees" produces a different diagram to "this flowchart is for the engineering team" — different labels, different assumed knowledge, different level of detail. One clause, big consequences.

Habit 03

Change one thing at a time

Ask for a single feature or a single fix per turn. When five changes arrive together and something breaks, you can't tell which one did it. Incremental iteration isn't slower — it's the only way to keep hold of what's working.

The through-line from Lesson 03: the first artifact is a draft, exactly like the first answer. The panel exists so you can keep working on it, not so you can admire it.

Station 04

Who gets to see it

Three ways out, and they differ in exactly one respect that matters: the size of the audience you're handing it to. Pick by audience, not by convenience.

Audience · you

Copy or download

Buttons in the lower right of the artifact window. The file goes to you, and travels only where you send it.

Audience · your colleagues

Share inside your organisation Team & Enterprise

Stays within the organisation and requires team authentication to open. Nobody outside can reach it.

Audience · anyone

Publish publicly Free, Pro, Max

Use the Share or Publish button in the upper right. What that means:

  • Only the version you select goes public — your chat stays private.
  • Anyone can open and interact with it without a Claude account.
  • Others can remix it — open it in their own conversation and build on it.
  • You can unpublish at any time by returning to the artifact and removing public access.
Read this before you publish anything

"Not indexed by search engines" is not a guarantee

Course material on artifacts often states flatly that published artifacts won't turn up in Google. The accurate version is narrower, and the difference matters.

  • What's true: Anthropic says it doesn't share chat directories or sitemaps with search engines like Google. Share URLs are long and random, so nobody guesses them.
  • What doesn't follow: that they can't be found. A published artifact is a public web page with no login. Anthropic has said these pages become searchable on third-party search engines once the link has been shared somewhere a crawler can see it — a forum, a social post, a website.
  • It has already happened. In late July 2026 people found that a simple site: search on claude.ai surfaced publicly shared conversations and artifacts — including material that plainly was never meant for strangers.
  • Unpublishing isn't a time machine. Pages already indexed or cached can keep appearing until search engines refresh them.

Sources: Anthropic statements reported by TechCrunch and Axios, 27 July 2026; incident coverage by Axios, Futurism and Cybernews. Check your own published links under Settings → Privacy → Shared Chats.

The working rule: treat "anyone with the link" as "anyone." If you wouldn't post it on a public website under your own name, don't publish it — share it inside your organisation, or send the downloaded file instead.

The habit worth forming: before you hit publish, read the artifact back once and ask what's in it that isn't yours to make public — a client name, a real figure, someone's contact details.
