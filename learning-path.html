What to do,
in order

Four stages. Set up, learn to talk to it, learn the machinery, then apply it. The prompt collections sit deliberately late — copy-paste before you understand the shape is how you end up with a library instead of a skill. Each row tells you what the lesson is, why it's at that position, and the one thing to actually do before moving on.

Three shorter routes

Not everyone needs all fourteen. Pick the route that matches how much time you actually have.

The 30-minute route

You just want to be better by lunchtime
  1. Lesson 02 — stage, task, rules
  2. Lesson 00 — make one Project
  3. Vol 1 — fix three habits you recognise
  4. Use one on real work today

The teaching route

You're showing this to friends
  1. Show three pairs from Vol 1 as a hook — not the whole library
  2. Lesson 01 — make them guess out loud
  3. Lesson 08 — let them click the toggles
  4. Lesson 10 — the quiz, as a group
  5. Lesson 00 — set it up together at the end

The full route

You want the whole thing to stick
  1. The table above, top to bottom
  2. One lesson per sitting, not twelve in a row
  3. Do the "action" column every time
  4. Finish on Lesson 11 and actually run one guide

The order matters in exactly one place. Lesson 00 goes first. Everything else in this course gets better once Claude already knows who you are — and every hour you spend learning to prompt while re-explaining yourself each session is an hour spent solving the wrong problem.
