Lesson 12 · Surfaces · read in ~6 minutes

Claude comes
to you

Eight more places Claude turns up — a terminal, a Slack thread, four Microsoft sidebars, a browser panel, a design canvas. They aren't eight products to learn. They're one assistant meeting you in rooms you were already sitting in, so the routing question isn't "which tool" — it's "where am I right now?"

Seven of these eight rooms are places you were already sitting. Only one is somewhere you go.

The reframe

You don't go to Claude. Claude comes to the room.

Every surface here exists to remove the same friction: leaving the thing you're working in, explaining it somewhere else, and carrying the answer back. Claude for Word exists because the document is already open. @Claude exists because the thread is already in Slack. Once you see that, you don't have to memorise eight products — you just notice where you are.

Part 02

Five rooms, eight doors

Grouped by what kind of room it is, because that's what tells you what the surface is genuinely good at.

Room 01

Where the code is

Terminal · IDE · browser · Slack

Claude Code is an agentic coding tool that understands your codebase, executes commands, and handles whole development workflows through natural language.

What makes it different: it doesn't just suggest — it runs. Commands, tests, commits.

Reach for it when

  • You want to build a feature by describing it in plain English and have Claude write the code, run the tests, and create the commits.
  • You need to debug — paste the error, let Claude analyse the codebase to find and fix the problem.
  • You're navigating an unfamiliar codebase and want to ask how different parts fit together.
  • You want to automate the tedium: lint errors, merge conflicts, release notes.
  • You'd rather stay in your terminal alongside your existing tools than switch to a separate interface.
Room 02

Where the team is

Slack workspace

@Claude joins your Slack workspace, so the context it needs — the thread, the channel history, the shared files — is already around it.

What makes it different: it already has your team's conversation. Nothing to paste in.

Reach for it when

  • You want to draft a reply, summarise a long thread, or break down a complex discussion without leaving Slack.
  • You're preparing for a meeting and want relevant conversations and shared documents pulled together.
  • You're onboarding to a new team and want the ongoing projects explained from the channel history.
  • You want to hand off a coding task straight from a bug report — tag @Claude and it can spin up a Claude Code session using the surrounding context.
  • You need a quick answer on an industry trend, a technical concept, or something about the company mid-conversation.
Room 03

Where the document is

Microsoft 365 sidebars

Four sidebars — Word, Excel, PowerPoint and Outlook — so you can work on the file that's already open in front of you.

What makes it different: it edits in place, keeping your template, your brand styling, your tracked changes. Compare that with Chat, which hands finished files back as downloads.

Claude for Word

  • Turn an outline or rough notes into a structured first draft in your team's template.
  • Revise a section — tighten the writing, adjust tone for a specific reader, rework the structure — without leaving the document.
  • Work through reviewer comments and tracked changes in place.
  • Ground the draft in connected source material, so claims trace back to where they came from.

Claude for Excel

  • Understand how formulas and calculation flows work across a complex multi-tab workbook.
  • Update assumptions or inputs across a model while preserving formula dependencies.
  • Debug #REF!, #VALUE! and circular references — trace them to their source and get suggested fixes.
  • Create new spreadsheets or populate templates while keeping the formula structure sound.
  • Build pivot tables and charts quickly.

Claude for PowerPoint

  • Turn an outline, document or set of notes into a first-draft deck without building each slide by hand.
  • Rewrite or tighten slide copy — shorten bullets, add speaker notes, adjust tone for the audience.
  • Restructure an existing deck: reorder sections, split dense slides, merge overlapping ones.
  • Apply consistent formatting across the whole deck instead of fixing each slide manually.
  • Get a quick suggestion on which layout or chart type fits the point you're making.

Claude for Outlook Beta · installs separately

  • Triage your inbox without leaving it.
  • Draft replies with context pulled from related threads and your calendar.
  • Turn a long email chain into a clear summary, or a set of next steps.
  • Note: this one is installed separately from the other Microsoft 365 add-ins — if you've installed the others and can't find it, that's why.
Room 04

Where the web is

Chrome sidebar

Claude in Chrome reads the page you're on and can act on it — clicking, filling, navigating between tabs.

What makes it different: it keeps context as you move between tabs, which is what makes it good at niche internal tools, CRMs and dashboards that have no connector.

Reach for it when

  • You want to summarise an article, paper or page while browsing.
  • You need help drafting email responses or managing your inbox.
  • You're filling out repetitive forms and want the process automated.
  • You want to test website features or walk a multi-step workflow without clicking through every step.
  • You need a browsing assistant that holds context across tabs and tasks.
Room 05

A room of its own

Web

Claude Design is the exception on this page — the one surface you actually travel to, because a prototype needs a canvas that no sidebar can give it.

What makes it different: the output is an interactive prototype you refine by conversation, not a description of one.

Reach for it when

  • You want to go from a written brief, sketch or reference screenshot to a working UI prototype without writing code.
  • You're exploring design directions and want to generate and compare several variations quickly.
  • You want to iterate on layout, copy or interactions by describing the change rather than editing markup.
  • You want a prototype built on your team's design system, so what you hand off matches what engineering will build.
Part 03

Before you switch one on

Two of these eight are in beta, and one of them changes the risk picture enough to be worth a page of its own. Your course notes give you the rules — here's the reasoning behind them, because a rule you understand is a rule you'll actually follow.

Claude in Chrome · public beta

Why "trusted sites only" is the rule

A browser assistant reads whatever's on the page — and a page can contain text written by someone who isn't you. Anthropic names prompt injection as the biggest risk facing browser-using AI tools: malicious instructions hidden in web content that try to make Claude do something you never asked for. Their own example is an innocent-looking to-do list or email carrying invisible text telling Claude to fetch bank statements and share them.

  • The protections are real but not absolute. Anthropic reports their configuration reduces attack success to under 0.08% in internal testing — and says plainly that the chance is still not zero.
  • Some sites are off-limits by default. Certain high-risk categories are blocked outright, and Claude asks permission before touching financial sites.
  • Start with sites you trust, and be wary of pages carrying user-generated content from unknown sources — that's where injected instructions live.
  • Confirm before anything sensitive. Purchases, sharing personal data, anything irreversible.

Source: Anthropic Help Centre, "Use Claude in Chrome safely", checked August 2026.

The setting your notes don't mention

There are three permission modes, not one

Your course material says the extension "asks for permission before high-risk actions" — true of the default, but there's a dropdown on the chat input with three settings, and the one you choose is your safety posture.

Manually approveClaude pauses before every action and you allow or deny each one. The safest option, and the one to start on.
Automatically approveClaude keeps working but checks each action for safety, blocking what it judges unsafe and pausing when it needs you. Fewer interruptions — and it uses more of your usage limit, because of the extra checking.
Skip all approvalsClaude doesn't pause and nothing checks its actions automatically. Only for tasks where you trust every action, connector, file and app involved.

Source: Anthropic Help Centre, "Claude in Chrome permissions guide", checked August 2026.

Claude for Outlook · beta

It installs separately

Outlook is not bundled with the other Microsoft 365 add-ins. If you've installed Claude for Word, Excel and PowerPoint and the Outlook sidebar never appeared, nothing is broken — it's a separate install.

The habit worth carrying: the more a surface can act rather than just answer, the more the permission screen matters. A sidebar that drafts a paragraph and a sidebar that clicks buttons on your behalf are not the same kind of tool.
