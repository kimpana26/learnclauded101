Lesson 04 · The desktop app · read in ~7 minutes

Three shapes
of work

The desktop app is your home base — from a quick question mid-meeting to a report Claude assembles from six sources while you do something else. The work sorts into three shapes, and knowing which one you're in is the whole skill of this lesson.

Start here

You won't pick a tab first.
You'll notice what kind of work is in front of you — and the tab follows.

So read the signals below, not the product names. The first two shapes are where most knowledge workers spend the day; the third is the developer's workspace.

Lives in Chat

You notice…

  • The answer changes what you ask next. You couldn't have written the whole request up front, because you didn't know yet.
  • You want to stay in it. The point is your judgment on every turn, not a finished thing at the end.
  • It's quick. A question, a rewrite, a "what does this mean?" — small enough that setting up a task would be overhead.
Lives in Cowork

You notice…

  • Several steps you'd do in sequence. Pull the figures, compare, draft, format.
  • The output is a real deliverable. A doc, a sheet, a deck — saved where you need it.
  • The work spans your tools. Notes here, a Slack thread there, numbers in a spreadsheet.
  • It should run on a schedule, or while you're doing something else.
Lives in the Code tab

You notice…

  • The work is inside a codebase. Reading it, writing it, running it.
  • You need the developer's instruments — diffs, a terminal, version history you can roll back.
  • Not a developer? This one is a separate tab and this course doesn't need it.
01

Working turn by turn

Chat

Claude as a thinking partner: the value is in the exchange itself. You bring a half-formed idea, an unfamiliar dashboard, a paragraph that isn't landing — and you work it out together, one turn at a time.

Reach for it when
  • The answer changes what you ask next. You're brainstorming, and each response opens the next question.
  • You want to stay in it. Drafting, editing, thinking out loud — your judgment on every turn.
  • It's quick. A question, a rewrite, a "what does this mean?"
Try it out when
  • An unfamiliar dashboard. Screenshot it, ask "what do these metrics mean?" Claude explains while it stays in view, and "which of these should I actually worry about?" is the next turn.
  • Between meetings, structuring a talk. Say it out loud, Claude drafts an outline, you push back on section three, it revises. Four turns, done before your next call.
  • Ideas scattered across weeks of notes. Ask Claude to pull the launch together, find what you left half-finished, check your other connected tools for gaps — then work the gaps together.
What running on your own machine adds
Quick entry MacDouble-tap the Option key to pull Claude up over whatever you're working on. It answers in a compact window that stays on top as you switch apps.
Screenshots & window sharing MacCapture a screenshot or share a window so Claude sees what you see.
Dictation MacTalk through a problem instead of typing it.
Desktop connectorsConnect local tools and services so Claude can work with what's already on your machine.

The tell: if you can't write the whole request up front, you're in this shape. Not knowing yet is the reason to stay here.

02

Handing work off

Cowork

Instead of asking a question, you hand over the whole piece of work — gather the context, do the analysis, produce the finished thing — and it comes back done. You're delegating, not chatting. For most people this is a genuinely new way of working, which is why it feels unfamiliar before it feels obvious.

Reach for it when
  • Several steps you'd normally do in sequence. Handed off, that's one instruction — not four errands.
  • The output is a real deliverable. A doc, spreadsheet, deck or formatted PDF, saved where you need it rather than pasted into a chat for you to reassemble.
  • The work spans your tools. Set a Friday roll-up as a scheduled task and Claude gathers all the sources itself, every run — nothing for you to round up first.
  • It should happen on a schedule, or while you're doing something else.
Try it out when
  • You want to query your tools like a database. "Review what we decided about pricing last quarter across meeting notes, Slack and email, then update the Q3 deck with the findings." Hand it off, keep working, check the result.
  • A folder of 50+ documents — contracts, financial reports, transcripts. Ask for the ones relevant to your initiative plus a summary memo. It reads every page and finds the patterns that only show up across all of them. Review fifty like you'd review five.
  • The same Monday-morning routine. Set it up once as a scheduled task and start the week with answers instead of admin.

Handing off ≠ stepping back

  1. Before it starts, Claude may ask a few questions to pin down scope and format.
  2. It shows you the plan before doing the work.
  3. As it runs you can watch it take shape — the sources it's drawing from, the files forming, its progress through the plan — and steer at any point.
  4. Set to ask before acting, it stops for your approval on the things that matter, like sending an email or sharing a file. You stay in control of what leaves your desk.
What Cowork gives you today
Local folder accessPoint Claude at a folder; it reads what's there and saves finished work back to the same place.
Scheduled tasksSet a task once and it runs on your cadence. If your computer or the app was closed at the time, it catches up when you're back.
SubagentsFor a big job, Claude splits the work across background workers running in parallel, each with its own context, and hands you one finished deliverable.
ProjectsGroup related tasks into a workspace with its own files, instructions and memory — like projects in Chat, but built around the tasks you run.
Browser useWith Claude in Chrome, it navigates sites and pulls what it finds straight into the task — competitor pricing across ten sites, data from pages with no API.
Computer use Pro & Max · research previewWhen no connector exists, Claude can operate your computer directly — clicking, typing, opening apps — asking permission before each app it touches, with a blocklist for anything off-limits.
PluginsReady-made bundles of skills, connectors and agents built for a kind of work — sales, finance, legal — so Claude works the way that role works. Add them under Customize → Plugins.

Availability: Cowork is for Pro, Max, Team and Enterprise users, with new capabilities added regularly.

The tell: if what you want at the end is a thing rather than a conversation, you're in this shape.

03

Building software

Code tab Developer's workspace

Not a developer? The takeaway is genuinely just this: it's a separate tab, and this course doesn't need it. Skip to the router. Knowing it exists is enough.

A full development environment. Claude works directly in your codebase — reading what's there, writing and modifying code, running commands. Visual diffs show what changed, a built-in terminal shows commands as they run, and git tracks every version so you can always roll back.

Where the work happens
  • Local. Select a folder and Claude works directly with those files — reading your project, using local tools, running a dev server you can preview in your browser.
  • Cloud. Connect a GitHub repo and Claude works in a cloud environment. Sessions continue even if you close the app, so you can start a big refactor and check back later. Good for larger codebases, or keeping work off your machine.
How much Claude does alone
  • Manually approve. Claude proposes every change and waits for you.
  • Accept edits. Claude applies file edits automatically.
  • Plan. Claude writes a plan before making any changes.

In the product today: the Code tab of the desktop app, on Pro, Max, Team and Enterprise plans. You can run multiple sessions across projects and filter them by environment (Local or Cloud) and status from the sidebar.

The line people actually blur

Shapes 01 and 02 are the two you'll switch between all day, and the boundary is easy to miss. One concrete difference settles it.

Turn by turn · Chat

Reads what you upload

You give it a file, it works with the file — and it hands finished work back as a download for you to file yourself.

Handing off · Cowork

Works inside your folder

You point it at a folder, it reads what's there, and it saves the finished work back into that same place. Nothing to move afterwards.

One question decides it: do you want to be in the exchange, or do you want the thing? Stay in Chat when the back-and-forth is the work. Move to Cowork when what you want is a finished artefact sitting where it belongs.
