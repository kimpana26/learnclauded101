If you're teaching someone else with this

Four things that make it land

  1. Make them guess first. Lessons 01 and 10 hide their answers behind a click for a reason — reading the answer teaches almost nothing, getting it wrong teaches a lot.
  2. Start with the prompt library, not Lesson 01. People believe the "instead of / try this" pairs immediately, because they recognise their own bad prompt. Then the lessons explain why.
  3. One lesson per sitting. They're short on purpose. Twelve in a row is a lecture; one a day is a habit.
  4. Have them run one thing. Reading about a capability and using it once are different kinds of knowing. Lesson 11 exists to get them to do exactly one real task.
